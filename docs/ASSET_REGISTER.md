# 仮素材と利用条件

この変更には外部の画像、音声、モデル、フォント、マーケットプレイス素材を同梱していません。10種類の名前・説明と配置データは今回作成したテキストです。エンジンのバイナリ素材はコピーせず、利用者が導入する UE 内の素材を参照します。

| 対象 | 出典・用途 | 利用条件と現状 |
|---|---|---|
| Cube | Epic Games / `/Engine/BasicShapes/Cube.Cube`。倉庫と仮アイテムの形状 | UE 付属コンテンツ。UE のライセンス条件の下でゲームに組み込む前提。素材単体を独立した無料素材として再配布しない |
| First Person テンプレート | インストールした UE の Games → First Person | Epic の公式テンプレート。導入版に含まれる素材・コードと利用条件を Windows で確認して取り込む。現在は未導入・未同梱 |
| ポイントライト | UE の組み込み Actor | 外部テクスチャ・HDRI は使わない |

公式の確認先は [Unreal Engine EULA](https://www.unrealengine.com/en-US/eula/unreal) です。UE は商用ゲームの制作に使用できる条件を備えていますが、付属素材が無条件に権利放棄されるわけではありません。利用する版の EULA と、そのテンプレート内に別の通知がある場合はその通知に従います。

この環境から公式 EULA 本文を取得する試行は HTTP 403 になりました。そのため **現行 EULA 本文の再確認と実際のインストール素材の確認は未完了**です。外部素材を追加して代用してはいません。Windows でエンジンを導入する際に確認します。今後素材を追加する変更では、取得元・作者・ライセンス・商用利用条件をこの表に追記します。
